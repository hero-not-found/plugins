# Plum for Claude

![Plum](assets/mark-light.png)

Recall conversations, find contacts, and summarize what matters from your Plum account.

MCP endpoint: `https://api.getoptima.com/mcp`.

In Claude, open this plugin from Customize › Plugins and select Connect on its Connectors tab. In Claude Code, use `/mcp` to authenticate this plugin's server. Each environment requires a separate connection.

Invoke `/plum:recall` to recall conversations.
